01 · 이 가계부의 관점

기록을 쌓고, 돌아보고,
다음 선택에 써먹어요.

수입·소비·저축·투자를 구분해 적는 기본기에, 소비를 돌아보고 생활을 계획하는 흐름을 더했어요.

01 / 소비 돌아보기

적게 쓴 날보다,
잘 쓴 돈을 알아가요.

소비마다 ‘후회돼요’와 ‘만족해요’를 선택할 수 있어요. 통계에서 각각의 건수·합계·내역을 모아 보고, 내게 가치 있었던 지출을 찾아보세요.

내역 → 소비 평가 / 통계 → 소비 돌아보기
02 / 반복 관리

매달 같은 돈은,
다시 적는 일을 줄여요.

월세·구독료·적금처럼 반복되는 내역을 월 단위로 기록해요. 금액이 바뀌면 적용 범위를 고르고, 잠시 멈출 때는 중지했다가 재개할 수 있어요.

내역 → 고정지출 / 고정지출 탭
03 / 생활 계획

“잠시 쉬어도 될까?”
숫자로 가정해 봐요.

현금·비상금·생활비·복귀 후 수입으로 1~3년의 예상 잔액을 살펴봐요. 생활비를 10·20·30% 줄였을 때의 차이도 비교할 수 있어요.

02 · 처음 시작하기

오늘 쓴 돈 한 건부터 시작하세요.

처음부터 지난 내역을 모두 옮기지 않아도 괜찮아요. 예시 화면을 보고, 오늘 기록 하나를 저장해 보세요.

  1. 먼저 둘러보기

    가계부를 열고 ‘화면 먼저 둘러보기 →’를 누르세요. 예시 데이터로 화면을 체험할 수 있어요.

  2. 내 계정 만들기

    미리보기를 종료하고 ‘처음이신가요? · 회원가입’에서 아이디·비밀번호를 정해요. 계정이 있으면 로그인하세요.

  3. 오늘 내역 적기

    내역에서 날짜를 고르고 소비·카테고리·세부내역·금액을 입력해요. 예를 들어 카페 / 커피 / 4,500원처럼요.

  4. 저장하고 확인하기

    ‘하루 전체 저장’을 눌러 완료 안내를 확인하세요. 요약에서는 월 합계, 통계에서는 소비 비중을 볼 수 있어요.

미리보기와 내 기록은 달라요. 미리보기의 입력은 실제 계정에 저장되지 않아요. 내 기록을 남길 때는 로그인하고, ‘저장 전’ 표시가 남아 있지 않은지 확인하세요. 실제 내역은 오늘 또는 지난 날짜에 기록할 수 있어요.

03 · 화면별 사용설명서

궁금한 화면을 골라 보세요.

가계부에는 여섯 가지 화면이 있어요. 로그인 후에는 ‘내역’에서 시작해요. 아래 그림과 숫자는 설명을 위한 예시예요.

설명을 볼 가계부 화면 선택
요약

이번 달, 얼마나 남았을까요?

기록한 수입과 지출을 기준으로 여유자금 또는 부족액을 확인하는 화면이에요.

  1. 조회할 월을 선택하세요.
  2. 여유자금·부족액과 수입·소비·저축·고정지출 합계를 확인하세요.
  3. 기록을 고치려면 ‘이달 내역 보기’, 앞으로의 생활비를 가정하려면 ‘생활 계획 세워 보기’를 누르세요.
한 달 계산 예시가상 금액
  • 수입3,000,000원
  • 소비− 1,100,000원
  • 저축− 600,000원
  • 투자− 200,000원
여유자금1,100,000원

고정지출은 소비·저축·투자에 이미 포함돼요. 별도로 한 번 더 빼지 않아요. 실제 은행 잔액과는 다를 수 있어요.

내역

하루의 돈 흐름을 기록해요.

수입·소비·저축·투자를 구분해서 입력해요. 소비에는 선택 사항으로 만족·후회 표시를 남길 수 있어요.

  1. 이전 날·오늘·다음 날이나 달력으로 날짜를 고르세요. 달력의 날짜를 한 번 누르면 아래 내역이 바뀌고, 같은 날짜를 빠르게 두 번 누르면 큰 날짜 화면으로 돌아와요.
  2. 새 내역에 구분·세부내역·카테고리·금액을 채우세요. 카테고리 자동 선택이 맞는지 확인하고, 없으면 ‘+ 직접 추가’로 만들어요.
  3. 기존 기록은 ‘수정’으로 펼쳐 바꿔요. 소비의 ‘이 소비, 어떠셨나요?’는 선택하지 않아도 돼요.
  4. ‘하루 전체 저장’으로 변경을 저장하세요. ‘접기’는 저장이 아니에요. 날짜나 화면을 옮길 때 변경 확인이 나오면 저장 여부를 골라 주세요.

소비 · 카페 만족해요

충동 구매29,000원

소비 · 잡화 후회돼요

하루 전체 저장 · 실제 앱에서 누르세요

원화 외에도 달러·엔·유로·위안을 입력할 수 있어요. 외화는 환율과 원화 정산액을 확인하고 저장하세요.

통계

숫자에서 내 습관을 찾아요.

어느 분류에 많이 썼는지, 다른 기간과 무엇이 달라졌는지 살펴보세요.

  1. 통계 월 선택에서 한 달을 고르세요. ‘여러 월 선택’을 켜면 떨어져 있는 달이나 다른 연도의 달도 함께 볼 수 있어요.
  2. 도넛 그래프에 마우스를 올리거나 손가락으로 누르면 항목과 비중이 보여요. ‘내역 보기’ 또는 아래 카테고리 목록으로 세부 내용을 확인하세요.
  3. 일간·주간·월간 비교에서 기준·비교 기간을 고르세요. 그래프의 날짜를 누르면 정확한 금액을 확인할 수 있어요.
  4. ‘소비 돌아보기’를 펼쳐 만족·후회한 소비의 건수와 합계를 보세요. 내역을 누르면 해당 날짜로 이동해 수정할 수 있어요.

평가를 남긴 소비만 모아요. 평가하지 않은 소비가 나쁘다는 뜻은 아니에요. 나에게 의미 있었는지 돌아보는 표시예요.

고정지출 · 모바일에서는 고정

반복되는 돈은 따로 관리해요.

소비뿐 아니라 매달 하는 저축·투자도 반복 기록으로 관리할 수 있어요.

  1. 내역 → 구분 → 고정지출에서 소비·저축·투자와 세부 분류를 선택하고 저장하세요. 비슷한 기존 고정지출이 안내되면 확인한 뒤 추가 여부를 정해요.
  2. 고정지출 화면에서 진행 중인 항목과 월 예정액을 확인하세요. 예정액은 그달에 실제 기록된 합계와 다를 수 있어요.
  3. ‘금액 수정’에서 새 금액과 적용 범위를 선택하세요. ‘향후 반복 중지’로 멈추고, 다시 필요하면 기준일을 정해 ‘재개’하세요.

생활 계획 · 모바일에서는 계획

쉬는 동안의 생활비를 가정해요.

퇴사·휴직처럼 수입이 달라지는 시기에, 준비한 돈이 어떻게 변할지 살펴보는 계산 도구예요.

  1. 계산할 시작일과 1·2·3년 기간을 고르세요.
  2. 사용 가능한 현금·남길 비상금·월 생활비·고정비·저축을 입력하세요. ‘내 가계부에서 생활비 불러오기’는 최근 완료 3개월의 일반 소비와 진행 중 고정지출을 참고해요. 빠진 기록이 있다면 직접 조정하세요.
  3. 쉬는 동안의 수입과 복귀 시점·복귀 후 수입을 정하고 결과를 확인하세요.
  4. 생활비 10·20·30% 절감안과 예상 잔액, 비상금 아래로 내려가는 시점, 필요한 추가 현금을 비교하세요.
생활비를 20% 줄이면?단순 예시

일반 생활비 월 100만 원을 80만 원으로 조정하고 12개월 유지한다고 가정해요.

현재 일반 생활비 / 월100만 원
20% 절감 / 월80만 원
12개월 뒤 차이+ 240만 원

고정비·저축은 같다는 가정이에요. 실제 내역은 바뀌지 않아요. 계획 입력은 탭 이동 중 유지되지만 새로고침·종료하면 초기화돼요.

설정

내 생활에 맞게 정리해요.

자주 쓰는 분류와 화면을 정리하고, 저축 기록과 삭제한 내역을 관리할 수 있어요.

  1. 카테고리 관리를 펼쳐 분류를 추가하거나 이름·색상·아이콘·순서를 바꾸세요. 기존 기록이 있는 분류는 다른 분류로 옮긴 뒤 삭제해요.
  2. 화면 설정에서 기본 화면을 달력 또는 큰 날짜로 고르고, 일별 요약 표시 여부를 정하세요. 해·달 버튼으로 라이트·다크 모드도 바꿀 수 있어요.
  3. 예금·적금에서 상품명·가입일·만기일·과거 납입을 기록하고 매월 납입 기록을 연결하세요.
  4. 휴지통 · 삭제 후 30일에서 기록을 복원해요. CSV 내보내기에서는 기간을 골라 엑셀 등에서 열 수 있는 파일로 내려받으세요.

  • 기본 화면달력
  • 일별 요약표시
  • 기록 보관CSV 내려받기

화면·테마 선택은 현재 브라우저·기기에 저장돼요. 예금·적금의 입력 잔액은 직접 확인해 적는 값이며 은행에서 자동으로 가져오지 않아요.

04 · 부담 없이 이어가는 법

매일은 가볍게, 가끔은 깊게.

모든 항목을 완벽하게 채우기보다, 내 선택에 도움이 되는 기록을 남겨 보세요.

오늘 기록 + 느낌 한 가지

오늘 쓴 돈을 적고, 기억에 남는 소비에만 만족·후회 표시를 남겨요. 저장 완료도 확인하세요.

요약에서 여유자금·부족액을 보고, 안 쓰는 구독은 반복을 중지해요. 큰 변화가 있다면 생활 계획도 가정해 보세요.

05 · 자주 묻는 질문

쓰면서 궁금할 만한 것들.

질문을 누르면 답을 펼쳐 볼 수 있어요.

카드나 은행 내역을 자동으로 가져오나요?

현재는 직접 입력하는 가계부예요. 은행·카드·증권 계좌나 쇼핑몰 구매 내역의 자동 연동은 제공하지 않아요. 고정지출은 등록한 설정에 따라 가계부 기록을 반복 생성해요.

여유자금이 실제 통장 잔액인가요?

아니에요. 선택 기간에 기록한 수입에서 소비·저축·투자를 뺀 금액이에요. 이전부터 가지고 있던 자산이나 빠뜨린 거래는 자동 반영되지 않아요. 고정지출은 각 구분에 포함되어 따로 한 번 더 빼지 않아요.

모든 소비에 평가를 남겨야 하나요?

선택 사항이에요. ‘선택 안 함’으로 두어도 기록과 통계는 사용할 수 있어요. 만족·후회는 소비에만 표시하며, 고정 소비를 평가해도 그 회차에만 적용돼요.

카테고리가 자동 선택되면 바꿀 수 없나요?

바꿀 수 있어요. 이전에 같은 내용으로 저장한 분류를 먼저 참고하고, 해당 기록이 없으면 키워드로 제안해요. 직접 선택한 분류를 자동으로 덮어쓰지 않으니, 내 생활에 맞는 카테고리를 골라 저장하세요.

실수로 지웠거나 저장을 안 했다면요?

저장했던 내역을 삭제했다면 설정의 휴지통에서 삭제 후 30일 안에 복원할 수 있어요. 중지된 반복은 내역 복원만으로 재개되지 않아요. 작성 중인 변경은 ‘저장 전’으로 구분되며, 접기나 화면 이동을 저장으로 생각하지 말고 ‘하루 전체 저장’의 완료 안내를 확인하세요.

생활 계획의 결과대로 돈이 남는 건가요?

입력한 가정으로 월말 수입·지출을 합산한 예상치예요. 월중 결제일, 이자, 물가, 갑작스러운 지출은 반영하지 않아요. 생활비 절감률은 일반 생활비에만 적용돼요. 현금·수입과 불러온 지출을 확인하고 여유 있게 계획하세요.

휴대폰 앱도 설치할 수 있나요?

현재 안내는 브라우저에서 사용하는 웹 버전 기준이에요. Android·iOS용 코드와 기기 저장 기능은 준비 중이며, 서명된 설치 파일과 실제 기기 검수는 아직 완료되지 않았어요. 웹에서는 로그인해 서버에 내 기록을 저장해요.

CSV를 받으면 전체 백업이 되나요?

CSV는 선택 기간의 저장된 내역을 다른 프로그램에서 읽기 위한 파일이에요. 원금·통화·환율·원화 정산액을 포함하지만, 휴지통과 작성 중 초안은 제외해요. 모든 설정과 반복 규칙을 담는 전체 백업과는 달라요.

지금 이용할 수 있는 범위

이 설명서는 2026년 10월 25일 웹 버전의 구현과 화면을 기준으로 작성했어요. 아이디·비밀번호로 가입·로그인하고, 미리보기로 예시 화면을 둘러볼 수 있어요. 카카오 로그인은 아직 실제 연동 검증 전이에요.

이용 전에 알아 두세요

  • 현재 개인 계정의 기록을 관리하는 방식이에요.
  • 회원탈퇴는 데이터 삭제·백업 보관 정책 확정 전까지 비활성화되어 있어요.
  • 운영 PC·서버·연결이 꺼지면 로그인과 기록 조회가 어려울 수 있어요.
