# 나의 가계부 · 소개와 사용설명서

[설명서 열기](https://lirodek0106.github.io/household-finance-guide/)

가계부 소개·차별점·첫 사용 순서·화면별 사용법·자주 묻는 질문을 담은 정적 HTML입니다.
설명서는 운영 PC나 가계부 서버가 꺼져 있어도 GitHub Pages에서 열 수 있습니다.

- `index.html`: 마스코트와 스타일을 포함한 단일 파일입니다.
- `.nojekyll`: HTML을 그대로 게시하도록 설정합니다.
- 본문의 금액·내역은 모두 가상의 설명용 예시입니다.

[가계부 서비스](https://daily-ledger-dji.pages.dev/)의 로그인·기록 기능은 별도 운영 서버 연결이 필요합니다.
설명서 변경은 원본 프로젝트의 harness/deploy-github-guide.ps1로 다시 게시합니다.
이 저장소에는 실제 금융 기록·백업·비밀값이나 가계부 애플리케이션 소스를 포함하지 않습니다.
